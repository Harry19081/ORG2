Findings corrected in this change:

- The generic GPT-5 fallback overstated the context of GPT-5.4 Mini, GPT-5.3 Codex, and GPT-5.2, and understated GPT-5.4 and GPT-5.6 in the frontend. Specific entries now precede the family fallback in both catalogs.
- The frontend advertised 16K or 32K output for several Claude 4.5–5 models whose documented standard output is 64K or 128K. These are corrected, including both dotted and hyphenated Opus 4.5 IDs.
- Claude Opus 5.5 always uses adaptive thinking; Opus 5 can disable it. The Rust resolver now distinguishes them.
- GPT-6 Sol/Luna and Claude Opus 5.5 prices, 5-minute cache write prices, and cache read prices in the bundled price catalog match their [OpenAI Sol](https://developers.openai.com/api/docs/models/gpt-6-sol), [OpenAI Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), and [Anthropic Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview) pages. Claude's 1-hour cache write and batch beta output limit are outside the bundled catalog's standard-rate schema.

The GPT-6 API pages list `none` through `max` reasoning effort. ORGII's Codex OAuth effort variants are a separate CLI-facing selection surface; live CLI discovery remains authoritative for account-specific availability. GPT-6 Terra is absent from the built-in catalog because no released model page was found for it at the time of this audit.
