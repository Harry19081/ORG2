# MyRolesCustomStatusesSection UI audit

Scope: the two sections appended to Settings → Integrations → My Roles →
Presence (`MyRolesStatusTab`). Audited against the `Section` layout contract
(`src/components/layout/Section/tokens.ts`) and the settings-row precedents in
`src/modules/MainApp/Settings/sections/`.

Findings were applied in the same pass at the user's request, so the Line column
cites the post-fix location.
